TactileGeo for Windows 10/11 (64-bit). Download `TactileGeo-Setup.exe`, run it, and open TactileGeo from the Start Menu. No Python, Node.js or other tools are needed.

- Model A (geometry, EasyOCR, Liblouis UEB Braille, tactile QA, SVG export) runs on this computer, offline.
- Template (Demo) works offline.
- Model B is optional, needs internet, and uses your own OpenRouter API key, which is stored in Windows Credential Manager. No key ships in the installer.
- The installer is unsigned, so Windows SmartScreen may warn: choose "More info" → "Run anyway".
- If Microsoft Edge WebView2 is missing (rare on Windows 10/11), the installer downloads it, which needs internet once.

SHA-256 checksum: see `SHA256SUMS.txt`.
